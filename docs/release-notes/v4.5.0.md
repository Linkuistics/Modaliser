# Modaliser v4.5.0

The VSCode editor panel can now select existing browser, webview, diff, and
other resource-less tabs. Selection follows the tab's live editor group and
position, including after groups are reordered.

The Homebrew cask uses the updated postflight steps API to remove quarantine
from the installed app. The companion README also records the VSCode
main-process heap-exhaustion diagnosis and its remaining attribution limits.

## Adoption

1. Install Modaliser v4.5.0.
2. Use **Install VSCode Companion** to install companion **1.2.0**, then restart
   VSCode or reload each window when your running sessions can be interrupted.

Existing Grove cleanup bindings continue to work. If upgrading from before
v4.4.0, follow that release's Grove Leaf configuration adoption steps too.
