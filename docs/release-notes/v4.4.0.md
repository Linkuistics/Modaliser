# Modaliser v4.4.0

The **Grove Leaf** action now clears stale task tabs left behind when Grove
renames, moves, or deletes task files, then reveals the current task as before.
Cleanup also runs when no live task remains or the grove directory is gone.

Only clean, missing Grove task tabs from the initiating workspace are eligible,
including Markdown previews and tabs open in multiple editor groups. Existing
files, unsaved edits, unrelated deleted files, and other workspaces' tabs remain
open. Cleanup preserves focus and leaves tabs alone when a file check is uncertain.

## Adoption

1. Install Modaliser v4.4.0.
2. Use **Install VSCode Companion** to install the bundled companion **1.1.0**,
   then restart VSCode.
3. Copy the updated **Grove Leaf** composition and its imports from
   `~/.config/modaliser/sys/scheme/examples/vscode.scm` into your own config,
   then relaunch Modaliser.

Your existing config is not rewritten by an upgrade. Older companions continue
to support listing and focusing; without the updated companion, task reveal
still works but stale tabs are not cleaned up.

If your custom VSCode screen has no companion install row, add this inside
the screen (using your existing `code:` import prefix):

```scheme
(key "I" "Install / Update VSCode Companion" code:install-companion!
     'hidden code:companion-installed?)
```

Use a key outside your jump-label alphabets. Relaunch Modaliser to load the
row; it appears whenever this build's bundled companion is not installed.
Installing the companion does not update an older Grove Leaf binding: that
composition and its imports still need step 3 above.
